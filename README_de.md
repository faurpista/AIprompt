🔑 API-Schlüssel erhalten (API Key Setup)
​Für die Nutzung dieser Anwendung wird ein API-Schlüssel von Groq und/oder Google Gemini benötigt. Beide Anbieter bieten ein 100 % kostenloses Kontingent an.
​1. ⚡ Groq API-Schlüssel erhalten (Kostenlos)
​Groq bietet extrem schnelle Antwortzeiten für Open-Source-Modelle (z. B. Llama 3.3).
​Öffne die Seite Groq Console.
​Melde dich an (oder erstelle ein kostenloses Konto mit deinem Google- oder GitHub-Account).
​Klicke im linken Menü auf die Option API Keys (oder gehe direkt zu console.groq.com/keys).
​Klicke auf die Schaltfläche Create API Key.
​Gib einen Namen für den Schlüssel ein (z. B. my-html-app) und klicke auf Submit.
​Kopiere den angezeigten Schlüssel (Format: gsk_...), da er später nicht mehr in voller Länge angezeigt werden kann!
​2. ♊ Google Gemini API-Schlüssel erhalten (Kostenlos)
​Google Gemini ist ein hervorragendes Allround-KI-Modell für verschiedenste Aufgaben und Analysen.
​Öffne die Oberflache von Google AI Studio.
​Melde dich mit deinem Google-Konto an.
​Akzeptiere die Nutzungsbedingungen, falls du dich zum ersten Mal anmeldest.
​Klicke in der oberen/linken Seitenleiste auf die Schaltfläche Get API key (oder gehe direkt zu aistudio.google.com/app/apikey).
​Klicke auf die Schaltfläche Create API key.
​Wähle die Option Create API key in new project (oder wähle ein bestehendes Google Cloud-Projekt).
​Kopiere den generierten Schlüssel (Format: AIzaSy...).
​⚙️ Verwendung in der Anwendung
​Öffne die HTML-Anwendung in deinem Browser.
​Füge den/die kopierten API-Schlüssel in das entsprechende Eingabefeld / Einstellungsmenü ein.
​Speichere die Einstellungen – die Anwendung ist sofort einsatzbereit!
