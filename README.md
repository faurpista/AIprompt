## 🔑 API Kulcsok Beszerzése (API Key Setup)

Az alkalmazás működéséhez szükség van egy **Groq** és/vagy egy **Google Gemini** API kulcsra. Mindkét szolgáltató kínál **100%-ban ingyenes** csomagot a használathoz.

---

### 1. ⚡ Groq API Key beszerezése (Ingyenes)

A Groq extrém gyors válaszidőket biztosít a nyílt forráskódú modellekhez (pl. Llama 3.3).

1. Nyisd meg a **[Groq Console](https://console.groq.com)** oldalt.
2. Jelentkezz be (vagy regisztrálj egy ingyenes fiókot Google/GitHub fiókkal).
3. A bal oldali menüben kattints az **`API Keys`** opcióra (vagy menj közvetlenül a [console.groq.com/keys](https://console.groq.com/keys) címre).
4. Kattints a **`Create API Key`** gombra.
5. Adj meg egy nevet a kulcsnak (pl. `my-html-app`), majd kattints a **`Submit`** gombra.
6. **Másold ki a megjelenő kulcsot** (formátum: `gsk_...`), mert később már nem fogod tudni teljes egészében megtekinteni!

---

### 2. ♊ Google Gemini API Key beszerezése (Ingyenes)

A Google Gemini kiváló általános AI modell feladatokhoz és elemzésekhez.

1. Nyisd meg a **[Google AI Studio](https://aistudio.google.com)** felületét.
2. Jelentkezz be a Google-fiókoddal.
3. Fogadd el a felhasználási feltételeket, ha először lépsz be.
4. A bal felső/oldalsó sávban kattints a **`Get API key`** gombra (vagy menj közvetlenül a [aistudio.google.com/app/apikey](https://aistudio.google.com/app/apikey) oldalra).
5. Kattints a **`Create API key`** gombra.
6. Válaszd ki a **`Create API key in new project`** opciót (vagy válassz egy meglévő Google Cloud projektet).
7. **Másold ki a generált kulcsot** (formátum: `AIzaSy...`).

---

### ⚙️ Használat az alkalmazásban

1. Nyisd meg a HTML alkalmazást a böngésződben.
2. Illeszd be a kimásolt API kulcso(ka)t a megfelelő beviteli mezőbe / beállítások menüpontba.
3. Mentsd el a beállításokat, és az alkalmazás máris készen áll a használatra!
