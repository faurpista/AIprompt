​🔑 API Kulcsok Beszerzése (API Key Setup)
​Az alkalmazás működéséhez szükség van egy Groq, egy Google Gemini és/vagy egy Hugging Face API kulcsra (tokenre). Mindhárom szolgáltató kínál 100%-ban ingyenes csomagot a használathoz.
​1. ⚡ Groq API Key beszerezése (Ingyenes)
​A Groq extrém gyors válaszidőket biztosít a nyílt forráskódú modellekhez (pl. Llama 3.3).
​Nyisd meg a Groq Console oldalt.
​Jelentkezz be (vagy regisztrálj egy ingyenes fiókot Google/GitHub fiókkal).
​A bal oldali menüben kattints az API Keys opcióra (vagy menj közvetlenül a console.groq.com/keys címre).
​Kattints a Create API Key gombra.
​Adj meg egy nevet a kulcsnak (pl. my-html-app), majd kattints a Submit gombra.
​Másold ki a megjelenő kulcsot (formátum: gsk_...), mert később már nem fogod tudni teljes egészében megtekinteni!
​2. ♊ Google Gemini API Key beszerezése (Ingyenes)
​A Google Gemini kiváló általános AI modell feladatokhoz és elemzésekhez.
​Nyisd meg a Google AI Studio felületét.
​Jelentkezz be a Google-fiókoddal.
​Fogadd el a felhasználási feltételeket, ha először lépsz be.
​A bal felső/oldalsó sávban kattints a Get API key gombra (vagy menj közvetlenül a aistudio.google.com/app/apikey oldalra).
​Kattints a Create API key gombra.
​Válaszd ki a Create API key in new project opciót (vagy válassz egy meglévő Google Cloud projektet).
​Másold ki a generált kulcsot (formátum: AIzaSy...).
​3. 🤗 Hugging Face User Access Token beszerezése (Ingyenes)
​A Hugging Face hozzáférést biztosít több ezer nyílt forráskódú AI modellhez és az Inference API-hoz.
​Nyisd meg a Hugging Face oldalát.
​Jelentkezz be (vagy regisztrálj egy ingyenes fiókot a Sign Up gombra kattintva).
​Kattints a jobb felső sarokban található profilképedre, majd válaszd a Settings (Beállítások) menüpontot.
​A bal oldali menüben kattints az Access Tokens opcióra (vagy menj közvetlenül a huggingface.co/settings/tokens oldalra).
​Kattints a Create new token gombra.
​Válasszd ki a token típusát: Read (olvasási jog elegendő a modellek futtatásához és lekérdezéséhez).
​Adj meg egy nevet a tokennek (pl. my-html-app), majd kattints a Create token gombra.
​Másold ki a generált tokent (formátum: hf_...).
​⚙️ Használat az alkalmazásban
​Nyisd meg a HTML alkalmazást a böngésződben.
​Illeszd be a kimásolt API kulcso(ka)t / tokent a megfelelő beviteli mezőbe / beállítások menüpontba.
​Mentsd el a beállításokat, és az alkalmazás máris készen áll a használatra!!
