​🔑 Uzyskiwanie kluczy API (API Key Setup)
​Do działania aplikacji wymagany jest klucz API Groq i/lub Google Gemini. Obaj dostawcy oferują w 100% darmowe plany do użytku.
​1. ⚡ Pozyskiwanie klucza Groq API (Darmowe)
​Groq zapewnia ekstremalnie szybki czas odpowiedzi dla modeli open-source (np. Llama 3.3).
​Otwórz stronę Groq Console.
​Zaloguj się (lub zarejestruj darmowe konto za pomocą konta Google/GitHub).
​W menu po lewej stronie kliknij opcję API Keys (lub przejdź bezpośrednio pod adres console.groq.com/keys).
​Kliknij przycisk Create API Key.
​Wprowadź nazwę dla klucza (np. my-html-app), a następnie kliknij Submit.
​Skopiuj wyświetlony klucz (format: gsk_...), ponieważ później nie będzie możliwości zobaczenia go w całości!
​2. ♊ Pozyskiwanie klucza Google Gemini API (Darmowe)
​Google Gemini to doskonały uniwersalny model AI do różnorodnych zadań i analiz.
​Otwórz interfejs Google AI Studio.
​Zaloguj się swoim kontem Google.
​Zaakceptuj warunki korzystania z usługi, jeśli logujesz się po raz pierwszy.
​W lewym górnym rogu lub w panelu bocznym kliknij przycisk Get API key (lub przejdź bezpośrednio na stronę aistudio.google.com/app/apikey).
​Kliknij przycisk Create API key.
​Wybierz opcję Create API key in new project (lub wybierz istniejący projekt Google Cloud).
​Skopiuj wygenerowany klucz (format: AIzaSy...).
​⚙️ Użycie w aplikacji
​Otwórz aplikację HTML w swojej przeglądarce.
​Wklej skopiowane klucze API w odpowiednie pole tekstowe / menu ustawień.
​Zapisz ustawienia – aplikacja jest gotowa do użycia!
