🔑 Obtaining API Keys (API Key Setup)
​To run this application, you will need a Groq and/or a Google Gemini API key. Both providers offer 100% free tiers for usage.
​1. ⚡ Getting a Groq API Key (Free)
​Groq provides extremely fast response times for open-source models (e.g., Llama 3.3).
​Open the Groq Console page.
​Sign in (or register for a free account using your Google/GitHub account).
​In the left-hand menu, click on the API Keys option (or go directly to console.groq.com/keys).
​Click the Create API Key button.
​Enter a name for the key (e.g., my-html-app), then click Submit.
​Copy the generated key (format: gsk_...), as you will not be able to view it in full again later!
​2. ♊ Getting a Google Gemini API Key (Free)
​Google Gemini is an excellent general-purpose AI model for various tasks and analysis.
​Open the Google AI Studio interface.
​Sign in with your Google account.
​Accept the terms of service if this is your first time logging in.
​In the top-left or sidebar menu, click the Get API key button (or go directly to aistudio.google.com/app/apikey).
​Click the Create API key button.
​Select the Create API key in new project option (or choose an existing Google Cloud project).
​Copy the generated key (format: AIzaSy...).
​⚙️ How to Use in the Application
​Open the HTML application in your browser.
​Paste the copied API key(s) into the corresponding input field / settings option.
​Save your settings, and the application is ready to use!
