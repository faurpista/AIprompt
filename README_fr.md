​🔑 Obtention des clés API (API Key Setup)
​Pour faire fonctionner cette application, vous aurez besoin d'une clé API Groq et/ou Google Gemini. Les deux fournisseurs proposent des offres 100 % gratuites.
​1. ⚡ Obtenir une clé API Groq (Gratuit)
​Groq offre des temps de réponse extrêmement rapides pour les modèles open source (ex. Llama 3.3).
​Ouvrez la page Groq Console.
​Connectez-vous (ou créez un compte gratuit avec votre compte Google/GitHub).
​Dans le menu de gauche, cliquez sur l'option API Keys (ou allez directement sur console.groq.com/keys).
​Cliquez sur le bouton Create API Key.
​Donnez un nom à la clé (ex. my-html-app), puis cliquez sur Submit.
​Copiez la clé générée (format : gsk_...), car vous ne pourrez plus l'afficher en entier par la suite !
​2. ♊ Obtenir une clé API Google Gemini (Gratuit)
​Google Gemini est un excellent modèle IA généraliste pour diverses tâches et analyses.
​Ouvrez l'interface Google AI Studio.
​Connectez-vous avec votre compte Google.
​Acceptez les conditions d'utilisation s'il s'agit de votre première connexion.
​Dans le menu latéral/supérieur gauche, cliquez sur le bouton Get API key (ou allez directement sur aistudio.google.com/app/apikey).
​Cliquez sur le bouton Create API key.
​Sélectionnez l'option Create API key in new project (ou choisissez un projet Google Cloud existant).
​Copiez la clé générée (format : AIzaSy...).
​⚙️ Utilisation dans l'application
​Ouvrez l'application HTML dans votre navigateur.
​Collez la ou les clés API copiées dans le champ de saisie / menu de configuration correspondant.
​Enregistrez les paramètres, et l'application est prête à être utilisée !
